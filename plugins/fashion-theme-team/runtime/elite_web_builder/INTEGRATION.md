# Fashion Theme Team Integration Overlay

This runtime is optional and lazy-loaded. Installing the plugin does not import
provider SDKs, read environment files, or register every runtime tool in the
active agent context.

Authority order:

1. Repository `AGENTS.md`, session log, SOT, and active brand canon.
2. Fashion Theme Team contracts and approval boundaries.
3. Current authenticated official documentation.
4. This runtime's code and generic knowledge references.

The copied `knowledge/` directory is legacy archive material. It is never
SkyyRose canon and contains known retired fonts, stale colors, and stale product
facts. Specialists may use its generic techniques only after verifying them
against current authoritative sources. `prd.md` is deliberately non-executable.

`SKIPPED` is unresolved. It cannot produce `all_green`, and no self-heal loop
may weaken, disable, or reinterpret a failed gate. Paid providers, external
writes, image generation, deployment, and destructive actions remain approval
boundaries.
