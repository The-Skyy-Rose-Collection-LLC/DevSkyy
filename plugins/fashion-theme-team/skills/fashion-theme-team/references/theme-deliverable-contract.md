# Complete Theme Deliverable Contract

A full build is not complete until every applicable surface is `PASS`, or
explicitly `NOT_APPLICABLE` with authority.

## Theme foundation

- Valid theme metadata, bootstrap, setup, menus, widget areas, image sizes,
  enqueue/version strategy, editor support, customizer/settings, and safe defaults.
- Complete WordPress hierarchy for home, front page, page, post, archive,
  taxonomy, search, 404, headers, footers, and legal/content surfaces.
- Classic or block model is declared; `theme.json`, patterns, templates, and
  editor parity are included when applicable.
- Text domain, POT/JS translations, plural/context APIs, RTL, logical CSS, locale
  formats, structured data/SEO, privacy/consent, and browser support are covered.

## Experience and content

- Home, collection, search/filter, PDP, editorial/lookbook, brand/story, cart,
  checkout, confirmation, account, empty/error, and transactional surfaces.
- Route-by-route real copy/media matrix with provenance, rights, ratios, focal
  points, alt text, trust content, CTAs, navigation, and legal requirements.
- No placeholder copy, missing primary media, dead controls, silent empty states,
  unverified product facts, or incomplete responsive behavior.
- Every applicable page is specified section-by-section with customer intent,
  business purpose, components, data source, features, states, responsive changes,
  accessibility, analytics and acceptance evidence. Use the Fashion Theme Brain
  page blueprints and record explicit deviations.
- Design and implementation handoffs include a rendered HTML visual contract and
  schema-valid JSON machine/evidence contracts with matching stable IDs.

## Delivery

- Source and generated assets, dependency/license inventory, demo import,
  documentation, customization guide, compatibility notes, changelog, package
  exclusions, installable package, upgrade notes, and rollback plan.
- Demo import is authorized, idempotent, repeatable, licensed, duplicate-safe,
  and able to assign required pages, menus, terms, attributes, and settings.
