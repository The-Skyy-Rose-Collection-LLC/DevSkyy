# Design System Pod

The `fashion-design-system-engineer` is an architect commanding eight lazy
specialists. Only the architect and currently runnable specialists are loaded.

| Specialist | Artifact |
|---|---|
| `fashion-brand-systems-researcher` | Brand evidence and logo-off hypotheses |
| `fashion-token-foundations-engineer` | Token graph, transforms, and drift report |
| `fashion-typography-layout-director` | Type and editorial composition grammar |
| `fashion-component-commerce-engineer` | Component API and commerce state matrices |
| `fashion-motion-responsive-engineer` | Motion, responsive, fallback, and performance matrix |
| `fashion-accessibility-content-engineer` | WCAG, content, localization, and RTL matrix |
| `fashion-designops-governance-engineer` | Tooling, docs, release, migration, adoption, and cost plan |
| `fashion-visual-qa-red-team` | Independent adversarial visual PASS/REJECT |

The pod covers research/ground truth, foundations, tokens, typography,
composition, components, content, interaction, motion, accessibility,
responsive behavior, performance, developer tooling, docs, examples,
governance, versioning, migration, telemetry, security/provenance, cost routing,
visual regression, and bounded learning/self-healing.

Builder handoff requires a 100-point distinctiveness score of at least 85,
every category at least 70 percent, zero anti-generic instant fails, a passed
logo-off test, fresh 390/768/1440 evidence, and independent red-team approval.
Missing or skipped evidence is unresolved.
