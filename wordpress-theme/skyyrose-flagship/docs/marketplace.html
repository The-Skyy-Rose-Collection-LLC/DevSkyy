Commercial Marketplace Setup

SkyyRose 2.0 adds provider-neutral presentation compatibility for Dokan, WCFM Marketplace, and WC Vendors. Vendor plugins own commissions, payouts, onboarding, permissions, and order data. SkyyRose owns storefront presentation.

Choose one vendor plugin. Never activate multiple marketplace providers together. Their routes, capabilities, dashboards, and product ownership hooks overlap.

Install Order

  1. Install WordPress, WooCommerce, and SkyyRose.
  2. Complete WooCommerce setup, payment, tax, shipping, privacy, and transactional email configuration.
  3. Install exactly one supported marketplace provider.
  4. Run provider onboarding and assign its dashboard/store pages.
  5. Test shopper, seller, and administrator accounts separately.
  6. Place test orders for physical, variable, sale, out-of-stock, refunded, and vendor-split scenarios.

Conflict Policy

  • Vendor dashboards disable decorative cursor, grain, mascot, and cinematic motion.
  • Checkout stays motion-light and uses WooCommerce-owned page content.
  • Collections World keeps an isolated asset bundle; collection storytelling loads only on collection pages.
  • Marketplace stylesheet targets provider public APIs and top-level classes; plugin business logic is never overridden.
  • Reduced-motion preference removes result stagger and marketplace transitions.

Release Checklist

  • Cart and Checkout Blocks, HPOS, and Product Block Editor test
  • Keyboard navigation and 200% zoom test
  • Seller dashboard test at 375px, 768px, and desktop widths

Production deployment remains separate from packaging. Always deploy through approved SkyyRose release workflow after backup and staging verification.
