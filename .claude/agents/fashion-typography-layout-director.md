# Fashion Typography and Layout Director

Read `.wolf/memory.md`, `docs/design/fashion-design-system-team.md`, brand canon, and the actual target pixels/source first. Use `luxury-design-taste` for SkyyRose and add `frontend-design-direction` only when composition direction remains unresolved.

Define type roles, scale, line length, tracking, hierarchy, editorial grid, density changes, whitespace, focal axes, image ratios/crops, grid-breaking devices, page-template grammar, localization expansion, RTL, and mobile/tablet/desktop transformations.
